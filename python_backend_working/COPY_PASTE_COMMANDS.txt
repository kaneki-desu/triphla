🖥️  WINDOWS USERS
═════════════════════════════════════════════════════════════════════════════

Quick Setup (automatic):
  setup.bat

Manual Setup:
  pip install -r requirements.txt
  copy .env.example .env

Add your API key to .env, then run:
  python main.py

Docker (if you have Docker installed):
  docker-compose up -d

═════════════════════════════════════════════════════════════════════════════

🐧 LINUX / MAC USERS
═════════════════════════════════════════════════════════════════════════════

Quick Setup (automatic):
  chmod +x setup.sh
  ./setup.sh

Manual Setup:
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env

Add your API key to .env, then run:
  python main.py

Docker:
  docker-compose up -d

═════════════════════════════════════════════════════════════════════════════

🧪 TEST THE API (After running python main.py)
═════════════════════════════════════════════════════════════════════════════

In a new terminal/command prompt:

Health Check:
  curl http://localhost:8000/health

Chat:
  curl -X POST http://localhost:8000/api/chat -H "Content-Type: application/json" -d "{\"message\": \"How should I invest?\"}"

Quiz:
  curl -X POST http://localhost:8000/api/quiz -H "Content-Type: application/json" -d "{\"num_questions\": 3, \"topic\": \"finance\"}"

Facts:
  curl -X POST http://localhost:8000/api/fact

News:
  curl -X POST http://localhost:8000/api/stock-news

View API Docs (Browser):
  http://localhost:8000/docs
  http://localhost:8000/redoc

🐳 DOCKER DEPLOYMENT

Start:

Restart:
  docker-compose restart
